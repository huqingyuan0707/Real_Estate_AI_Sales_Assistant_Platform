## 已解决：终端窗口每分钟自动弹出又关闭
- 根因：计划任务 `\ProxyGuard` 每分钟（PT1M）直接跑 `powershell.exe ... proxy-guard.ps1`，PowerShell 控制台先建窗后隐藏（-WindowStyle Hidden 无效）→ 每分钟闪一次黑窗
- 修复：新增 `proxy-guard-silent.vbs` 包装器（WScript.Shell.Run 第二参数 0=隐藏、False=不等待），Set-ScheduledTask 把 ProxyGuard 动作改为 `wscript.exe "D:\...\proxy-guard-silent.vbs"`；手动 Start-ScheduledTask 验证 LastTaskResult=0，窗口不再闪现。守护逻辑/触发间隔不变
- 教训：execute_command 内联 PowerShell 带 `$var` 会被外层 shell 吞掉 → 一律写临时 .ps1 用 `-File` 执行（本次 diag_autostart.ps1 / fix_proxyguard_task.ps1 用完即删）
