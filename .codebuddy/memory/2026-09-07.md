## 记忆管理模块落地（三模块闭环补全）
需求：短期记忆=会话内近期消息+任务状态（窗口/摘要/Token预算控长）；长期记忆=仅用户明确授权的稳定信息（偏好/常用项目），支持查看/修改/删除；业务事实实时走 RAG/系统接口不入记忆；租户+用户隔离；敏感信息强制过期；写入前分类+授权。

实现：
- `backend/app/services/memory.py`：短期（内存，key=(tenant,user,thread)，MEM_WINDOW=12 条 + MEM_TOKEN_BUDGET=2000 est_tokens≈chars*0.75，超限滚动进 summary）+ 长期（data/memory_store.json 持久化，分类 preference/project/fact，正则敏感检测手机号/身份证/银行卡，敏感必须 expires_days 否则 1001 拒绝；未授权=pending 不注入；读取惰性清过期）
- API `/api/v1/memory`：GET/DELETE short/{thread_id}、GET/POST/PUT/DELETE long、GET stats
- `chat.py`：删除旧 `_HISTORY`，Query 改写与 messages 组装改用 memory.get_context；long_prompt_block（仅授权+未过期）注入 system 并注明"业务数据以检索为准"；ChatRequest 加 tenant_id/user_id（默认 default/admin）
- 前端：api/index.ts 加 7 个记忆方法；SettingsView 加"🧷 记忆管理"卡（表格+授权/编辑/删除+新增 dialog）；ChatView 输入区加 Delete 图标=清空本会话短期记忆

冒烟（全部通过）：pending 写入→PUT 授权→敏感无过期 1001 拒绝→敏感+7天写入→两轮 SSE 问答（第二轮"它的"经改写命中滨江花园）→short 记忆 4 条 est_tokens 119/2000→清空+删除。前端 vite build ✓（10.8s）。测试请求体留在 backend/tests/mem_*.json、chat_r*.json（PowerShell 内联中文 JSON 会挂，必须 @file）。

## 图生图装修（毛坯房照片 + 业主定制）落地
需求：上传真实毛坯房照片 → AI 保持房间结构/门窗/视角不变，按业主家具清单（沙发/桌/盆栽/电视/冰箱/地毯等 14 种）、墙面颜色（7 色卡）、地面材质（5 种）一键重绘装修效果图。
- **技术核心**：SiliconFlow Kolors 原生 img2img——payload 加 `image`（dataURL base64）+ `strength`（0.4~0.9 控结构保持度）；输出尺寸按原图比例算（最长边1280、8对齐）；Qwen-Image 是纯文生图不支持 image 参数，带照片时后端强制切 IMG2IMG_MODEL=Kolors
- render.py：FURNITURE_PROMPTS/WALL_COLOR_PROMPTS/FLOOR_PROMPTS 映射表（中英对照，英文提示词质量高）；RenderTask 扩展 photo_b64/photo_size/furniture/wall_color/floor_style/strength；_cloud_prompt 图生图分支强调 "keep room structure, window and door positions, camera angle exactly unchanged"；历史记录带参数快照
- endpoints/render.py：/generate 改 **multipart Form**（photo UploadFile ≤8MB 校验 image/*，furniture=JSON 数组字符串）；无照片仍走纯文生图
- 前端：request() body instanceof FormData 时不设 Content-Type（否则 multipart boundary 丢失必 500）；HouseEditorView 第三步 = 照片上传预览 + 家具 chips 多选 + 墙色色卡 + 地面 chips + el-slider 自由度；stage 支持"毛坯→AI装修后"对比视图
- 验证 ✓：stdlib 生成的毛坯测试图 → multipart 提交 → cloud done 约15s → 本地 2.1MB PNG，奶油墙/橡木地板/沙发/电视/盆栽/地毯全部按参数落地，窗户结构保持。冒烟脚本保留 backend/scripts/smoke_img2img.py（纯 stdlib 造 PNG，无 PIL 依赖）
