## 咨询：Hermes 首次设置向导三个选项怎么选（用户发设置界面截图）
- 用户截图停在 `How would you like to set up Hermes?` 首问。**核实当前状态：`%LOCALAPPDATA%\hermes\bin\hermes.cmd` 与安装目录存在，但 `~/.hermes/config.yaml`、`~/.hermes/.env` 都还不存在** → 向导尚未开始，一切从头
- 三选项（官方 quickstart 口径）：① **Quick Setup (Nous Portal)** OAuth 登录、免 Key、自动配 1 个模型 + Tool Gateway 工具集，费用计入 Nous 订阅（官方推荐）；② **Full Setup** 逐项 BYOK（自己选 provider/填 Key/选模型）；③ **Blank Slate** 只留 provider+model+File Ops+Terminal，其余全关、以后逐项 opt-in（会写死 `agent.disabled_toolsets`，`hermes update` 也不会偷开）
- 给出的建议：**网络能直连/有代理 → 选 1**；**国内直连或已有自己的 Key → 选 2（推荐 DeepSeek，注册简单、国内直连）**。结合这台机器此前 Clash 没在 7890 监听、git 代理残留的情况，无代理时选 1 可能卡在 OAuth
- 硬性约束提醒：**模型上下文必须 ≥64K tokens**，低于会被启动时拒绝；密钥写 `~/.hermes/.env`、非密钥设置写 `~/.hermes/config.yaml`，建议用 `hermes config set` 写入
- 走完向导后：**关掉当前终端、开新终端**（PATH 生效）→ `hermes`（或 `hermes --tui`）进入对话；常用 `hermes model / tools / setup / doctor / update / --continue`，对话内 `/help /tools /model /save`，多行输入 `Alt+Enter` 或 `Ctrl+J`
- 排障顺序：`hermes doctor` → `hermes model` → `hermes setup` → `hermes sessions list` → `hermes --continue`
